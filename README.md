# dsh-xhs-matrix — 小红书矩阵内容管理系统

小红书矩阵内容管理系统（dsh 双半插件）：多账号人设、已发布知识库与权重、Apify 爆款池、指标采集、专属创作台与草稿。

- Host 半（`exports "."`）在宿主进程运行：存储、`/api/dsh-xhs-matrix` 路由、agent 工具、Apify 采集、指标调度与矩阵创作会话。
- 浏览器半（`exports "./client"`）经 `package.json` 的 `dsh.client` 声明在 Web GUI 加载：侧边栏「矩阵」入口。
- 独立工具入口（`exports "./invariant"`）：`checkMatrixStoreInvariant` 存储版本契约断言。
- 全部基于官方 NPM SDK 实现，不修改 DSH 源码。

## 能力

| 能力 | 说明 |
| --- | --- |
| 账号与连接 | 管理矩阵账号、绑定真实小红书主页/标识、连接状态与采集配置 |
| 人设配置 | 结构化人设：定位、受众、擅长领域、文案/钩子风格、正文结构、禁用表达、选题标准、默认话题 |
| 已发布知识库 | 每个账号独立保存已发布笔记（标题+正文导入）与 0-5 人工权重；权重 5 优先参考、权重 0 作为负向经验 |
| 爆款池 | 经 Apify 适配器按人设方向采集公开爆款候选（标题/正文/来源链接），按账号隔离；采纳/忽略审核，已采纳条目作为创作参考 |
| 指标快照 | 按账号/笔记追加采集阅读、点赞、收藏、评论等快照，保留历史趋势 |
| 定时采集 | 按账号周期采集公开指标，失败保留历史并记录状态 |
| 专属创作台 | 按账号隔离的独立对话：只注入当前账号人设、知识库、权重与爆款池，复用 Harness 当前模型配置（`agent-default-model`）但隔离主工作区 |
| 草稿 | 与选题解耦的独立草稿：人工编辑标题/正文/标签/封面提示词，显式保存，不自动发布 |

## 安装

### 本地开发（link 模式）

```sh
# 在仓库根目录执行：链接本地包到 web profile
dsh plugin --profile web add "link:$(pwd)/packages/dsh-xhs-matrix"
```

### 直接从 GitHub 安装（推荐）

```sh
dsh plugin --profile web add "github:heguolin/dsh-xhs-matrix#path:/packages/dsh-xhs-matrix"
```

（pnpm 会克隆仓库并取 `packages/dsh-xhs-matrix` 子目录安装；构建产物已预提交，无需运行构建脚本；安装时需联网访问 GitHub。）

或经 Web GUI 的插件清单安装。

安装后重启 `dsh web`：插件行 `xhs-matrix` 插入 web profile，Host 半在宿主进程运行，浏览器半在 Web GUI 加载。

## 使用

### Web 界面（Client 半）

侧边栏出现「矩阵」入口，点击后打开混合布局面板：左侧为账号与模块导航，右侧为当前账号的独立工作区：

| 页面 | 功能 |
| --- | --- |
| 总览 | 多账号状态、连接状态、采集状态与「打开创作台」 |
| 已发布知识库 | 按账号查看已发布笔记，点击设置 0-5 权重；「导入笔记」粘贴标题+正文后台数据 |
| 爆款池 | 按账号查看爆款条目（标题/正文/来源链接/推荐分/理由）；「采集爆款」入库，待审核条目「采纳 / 忽略」，页内「配置 Apify」 |
| 创作台 | 按账号隔离对话：创作模式/完整知识库切换、保存最近结果为草稿 |
| 草稿箱 | 展开查看、人工编辑、标记 published/dropped、录入指标、查看生成依据 |
| 人设配置 | 结构化人设编辑（定位/受众/风格/钩子/结构/禁用/选题标准） |

设计原则：**配置走 UI（人设/账号），内容生成走创作台或对话**——生成结果只保存为草稿，由你人工发布。

### Agent 工具

| 工具 | 方向 | 用途 |
| --- | --- | --- |
| `xhs_today` | 读 | 今日决策：为每个（或指定 `account`）未发账号生成创作简报（人设 + 爆款池参考），供 agent 撰写文案与封面提示词 |
| `xhs_draft_save` | 写 | 持久化草稿；同账号 + 当日去重（`force: true` 可覆盖） |
| `xhs_virals` | 读 | 查询指定账号的爆款池条目（标题/正文/来源链接/审核状态/推荐分/理由），可按 `status` 过滤 |
| `xhs_accounts` | 读 | 账号与人设清单（只读；增删改在「矩阵」面板进行） |
| `xhs_draft_status` | 写 | 回填草稿状态（published/dropped）；published 且带 metrics 时触发 `xhs/feedback` 事件 |
| `xhs_notes` | 读 | 查询指定账号的已发布笔记知识库（标题、权重、最近指标） |
| `xhs_collection_status` | 读 | 查询指定账号的指标采集状态 |

典型对话流：问「今天要发什么」→ agent 调 `xhs_today` 拿到创作简报 → 按人设撰写文案 + 封面提示词 → `xhs_draft_save` 落库；发布后 `xhs_draft_status` 回填阅读量等指标，触发 `xhs/feedback` 事件（进化闭环数据源）。

### 数据与隐私

- 数据文件：`~/.dsh/dsh-xhs-matrix.json`（单文件 JSON，原子写 + 格式版本，当前 `version 3`）。
- 存储内容：账号、人设、草稿、已发布笔记、指标快照、爆款池条目、创作台会话与设置（含 Apify 采集配置）。**数据仅保存在本地文件，不含任何凭证**（不保存 Cookie 或登录态）。
- Apify 采集配置（Actor ID / API Token / 单次最大候选数）在「矩阵 → 爆款池」页内配置，超时与轮询上限使用默认值；Token 仅保存于本地数据文件，配置时会回显到输入框以方便修改；外部样本只保留分析所需字段。
- 后台真实数据需要账号授权；未配置合规授权 API 前，通过 CSV/JSON 手动导入兜底，并明确标记数据来源。
- 版本契约：存储文件必须携带格式版本；version 1/2 自动迁移到 version 3（v1/v2 的选题池与负向经验丢弃，v2 趋势样本转为爆款池待审核条目，草稿移除冗余 `topicId`）。

### 配置

插件 Config（经 settings 面板或 cordis.yml 修改）：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `locale` | `zh-CN` | 日期格式等 |
| `announceToAgent` | `true` | 是否向模型注入插件公告 |
| `enabled` | `true` | 插件总开关 |

Apify 采集配置（Actor ID / API Token / 单次最大候选数）在「矩阵 → 爆款池」页内配置，超时与轮询上限使用默认值，不属于插件 Config。

## 已知限制

- 后台真实数据依赖账号授权；当前以手动导入兜底。
- Apify 采集的是公开数据，不等同于小红书后台真实指标。
- 创作台实际可用上下文上限以当前配置模型能力为准，超出时明确提示。
- 定时任务只采集指标，不自动生成或发布内容。
